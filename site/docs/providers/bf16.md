# bf16.ai

[bf16.ai](https://bf16.ai) serves uncensored open-weight models (DeepSeek V4.1 Flash, GLM-5.3, GLM-5.3 Flash, Kimi K3.1 Pro) with 1,048,576-token context windows, automatic prompt caching, and strict Zero Data Retention (ZDR) behind an [OpenAI-compatible API](https://bf16.ai/docs). Use promptfoo's [OpenAI provider](/docs/providers/openai/) with bf16.ai's endpoint and API key — useful for security audits, red-team testing, and long-context evaluations where standard hosted safety filters trigger false-positive refusals.

bf16.ai documents its Zero Data Retention guarantees and acceptable use terms in its [privacy policy](https://bf16.ai/legal/privacy) and [terms of service](https://bf16.ai/legal/terms).

:::warning Safety

Models served on bf16.ai have refusal behaviors removed from the weights. Review outputs before using them in production applications and follow applicable laws and model licenses.

:::

## Setup

Create an API key in the [bf16.ai dashboard](https://bf16.ai/dashboard/keys) (new accounts include `$0.20` starter credit) and set `BF16_API_KEY` in your shell, or load it from a file with `--env-file`:

```sh
export BF16_API_KEY=sk-bf16-v1-your-key-here
```

```yaml title="promptfooconfig.yaml"
# yaml-language-server: $schema=https://promptfoo.dev/config-schema.json
providers:
  - id: openai:chat:deepseek/deepseek-v4.1-flash-uncensored-fast
    config:
      apiBaseUrl: https://api.bf16.ai/v1
      apiKeyEnvar: BF16_API_KEY
      headers:
        OpenAI-Organization: ''
      omitDefaults: true
      temperature: 0
      max_tokens: 4096
      showThinking: false

prompts:
  - 'Audit this route handler for authorization bypass bugs: {{code}}'

tests:
  - vars:
      code: 'app.post("/admin/delete", (req, res) => db.delete(req.body.id));'
    assert:
      - type: contains-any
        value:
          - authentication
          - authorization
          - middleware
```

`apiBaseUrl` overrides OpenAI endpoint environment variables. `apiKeyEnvar` selects only `BF16_API_KEY`; a missing key does not fall back to `OPENAI_API_KEY`. The empty `OpenAI-Organization` header overrides any inherited `OPENAI_ORGANIZATION` value.

## Configuration Notes

- `omitDefaults: true` omits promptfoo's default output limit and temperature so bf16.ai uses the values you set explicitly.
- `showThinking: false` excludes reasoning traces from the response string evaluated by assertions.
- bf16.ai also supports the OpenAI Responses API (`/v1/responses`) and native Anthropic Messages API (`https://api.bf16.ai/v1/messages`).
