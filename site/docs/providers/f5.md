# F5

[F5 AI Gateway](https://www.f5.com/products/ai-gateway) provides an interface for a handful of LLM APIs.

The F5 provider accepts the [OpenAI provider](/docs/providers/openai/) options, except
`apiKeyEnvar`, which the provider fixes to `F5_API_KEY`.

In the F5 AI Gateway, you can create paths that serve OpenAI-compatible endpoints. The name after
`f5:` is the gateway path, and it is appended to `apiBaseUrl` — so set `apiBaseUrl` to the gateway
origin only, without the path and without a trailing slash:

```yaml
providers:
  - id: f5:path-name
    config:
      temperature: 0.5
      apiBaseUrl: https://your-ai-gateway.example.com
      apiKey: YOUR_F5_API_KEY
```

That request goes to `https://your-ai-gateway.example.com/path-name`.

:::caution
`apiBaseUrl` is required and is concatenated verbatim. Omitting it produces a request to the
literal URL `undefined/path-name`; a trailing slash produces `//path-name`; and repeating the path
(`https://your-ai-gateway.example.com/path-name`) produces `/path-name/path-name`.
:::

If you prefer to use an environment variable, set `F5_API_KEY`.

For more information on the available models and API usage, refer to the F5 documentation for each specific model.
