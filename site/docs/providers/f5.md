# F5

[F5 AI Gateway](https://www.f5.com/products/ai-gateway) provides a gateway for LLM APIs.

The F5 provider accepts the [OpenAI provider](/docs/providers/openai/) options. It reads the API
key from `F5_API_KEY` by default; set `apiKeyEnvar` to use a different environment variable.

The name after `f5:` is the gateway path. Set `apiBaseUrl` to the gateway URL without that path:

```yaml
providers:
  - id: f5:path-name
    config:
      temperature: 0.5
      apiBaseUrl: https://your-ai-gateway.example.com
      apiKey: YOUR_F5_API_KEY
```

This sends chat requests to `https://your-ai-gateway.example.com/path-name/chat/completions`.

You can also set the gateway URL with `F5_API_BASE_URL`. `config.apiBaseUrl` takes precedence.
A trailing slash is fine. Leave the gateway path out of the URL or it will appear twice.
