# Repository instructions

Before any repository work, locate the Git root and use the file-reading tool to
read its `AGENTS.md` if it is not already in context. Claude may omit the root
import below when a session starts in a subdirectory.

Before inspecting or changing a file, also read every `AGENTS.md` between the Git
root and that file's directory. These are the canonical repository instructions.
